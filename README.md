# Shale Namma Pride 🏫✨

**Shale Namma Pride** is a modern, AI-powered School Showcase & Transparency Portal designed specifically for government schools. Built with a mobile-first approach, the app aims to bridge the gap between school management and parents while celebrating student achievements.

## 🚀 Key Features

- **School Transparency Portal**: A centralized hub for parents to view school updates, attendance, and administrative notices.
- **Mid-Day Meal Tracker**: Real-time updates of the daily meal menu with photo placeholders to ensure nutritional transparency.
- **Facility Gallery**: An interactive showcase of school infrastructure, including smart classrooms, labs, and libraries.
- **Siri AI Tutor**: A placeholder for a multilingual AI assistant (powered by Gemini) to help students with their learning journey.
- **Parent Feedback Portal**: A direct channel for parents to submit suggestions or complaints to school management.
- **Student Achievements**: Dedicated section for "Student of the Week" and other academic/extracurricular milestones.
- **Multilingual Support**: Toggle between **Kannada** and **English** to ensure accessibility for all stakeholders.
- **Admin Upload Panel**: A dedicated faculty interface for easy management of meal updates, notices, and achievements.

## 🎨 Modern UI/UX

- **Pride Theme**: A vibrant educational color palette featuring Crimson, Gold, and Deep Blue.
- **Dynamic Backgrounds**: Animated glow blobs and sophisticated gradients provide a high-energy, inspiring feel.
- **Glassmorphism**: Translucent headers and components for a premium, modern Android look.
- **Smooth Transitions**: Fluid screen switching using Jetpack Compose's `AnimatedContent`.

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Design System**: Material 3
- **Navigation**: Compose Navigation
- **Animations**: Compose Animation (InfiniteTransitions, AnimatedContent)
- **API (Future)**: Gemini AI for the Tutor, Firebase for Realtime Updates.

## 🏁 Getting Started

1. Clone the repository.
2. Open in **Android Studio Ladybug (or newer)**.
3. Sync the project with Gradle files.
4. Run the app on an emulator or physical device (Target SDK: Android 15/16).
